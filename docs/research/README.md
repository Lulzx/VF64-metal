Evidence labels used throughout:

- **Measured here**: executed by this project on the named Apple device.
- **Source-inspected**: present in a named upstream revision, not independently
  validated here.
- **Reported**: an upstream author claim.
- **Projected**: produced by an analytic model, not measured silicon.
- **Proposed**: a design or experiment that is not implemented.
