# Virtual FP64 milestones

This is the canonical delivery sequence for the project. A milestone is not
complete when source code merely exists; its stated exit evidence must exist
and be reproducible.

1. [M1 — Exact core arithmetic](M1-exact-core.md)
2. [M2 — Complete IEEE-754 runtime](M2-ieee-runtime.md)
3. [M3 — High-performance precision modes](M3-precision-modes.md)
4. [M4 — Virtual FP64 ISA](M4-virtual-isa.md)
5. [M5 — Compiler integration](M5-compiler-integration.md)
6. [M6 — Automatic precision selection](M6-auto-precision.md)
7. [M7 — Scientific workload proof](M7-workloads.md)
8. [M8 — 1.0 and research claim](M8-release.md)

The [experiment roadmap](../roadmap/experiments.md) lists near-term probes and
the [claim policy](../policies/claims.md) defines the evidence language. Current
progress and blocking artifacts are tracked in the
[milestone evidence ledger](../evidence/milestone-status.md).
